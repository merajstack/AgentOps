## Overview

AgentOps is an AI-driven automation platform that connects customers, managers, and business workflows into a seamless pipeline.

<b>Sample Workflow:</b>
```
Customer Inquiry
       │
       ▼
   Manager Approval
       │
       ▼
 Proposal Generation
       │
       ▼
   PDF Proposal
       │
       ▼
 Customer Approval
       │
       ▼
 Invoice Generation
       │
       ▼
  Invoice Delivered
```

<b>Test Workflow at:<b/> steel-agentops.vercel.app
